# AG Memory v0.25.13 — формализация эллипсиса и граница посылок М2

База: приложенный `AG_Memory_v0.25.12_verified(2).zip`.
Полный архив проекта, с сохранением архитектуры v4.

## Изменения кода

- Восстановление использует единственный фрейм указанной предшествующей клаузы. Удалён выбор последнего произвольного фрейма из всего сообщения, который мог брать более позднее утверждение.
- Неоднозначный источник, отсутствующий источник, повторные роли, неподтверждённый локальным evidence актант и неразрешённое отрицание отрицательного источника дают `AdaptiveParseError` с `UNRESOLVED` trace. Частичный разбор не выдаётся за успешный и не допускается к canonical integration.
- Идентификаторы восстановленных утверждений не сталкиваются с существующими local_id или ключами provenance map.
- Восстановленное утверждение сохраняет положение своей клаузы. Predicate evidence указывает на исходный предикат; assertion evidence — на восстановленную клаузу. Последующая сборка conditionals получает обе ветви.
- Группа `Мария и Пётр — нет` остаётся одной клаузой; `нет` распознаётся и после восстановленного фрейма.
- Наличие дальнейшего явного предиката не стирает признак локального эллипсиса после запятой.
- Предикат после следующей запятой не дробит группу `книгу и журнал` на ложные утверждения.
- Восстановлено повреждённое кодировкой имя `docs/reference/Архитектура_v3.md`; содержимое не менялось.

## Проверки

Добавлены **106** исполняемых проверок в двух файлах:

- `tests/test_ellipsis_invariants_02513.py`: 43 проверки восстановления, evidence, отказов, identity и комбинаций polarity/status/quotation.
- `tests/test_ellipsis_canonical_02513.py`: 63 проверки реальной pymorphy3-морфологии, границ клауз, conditional integration, proof eligibility и подстановок ролей в AH. Включены структурные регрессии по 25 кейсам последнего живого acceptance.

Новые тесты на исходном коде: **68 failed / 38 passed**.
Новые тесты на исправленном коде: **106 passed**.
С прежними тестами эллипсиса: **114 passed**.
Полный результат и точные ограничения — `TEST_RESULTS_02513.md` и `verification/02513/`.

## Запуск

В активированном окружении проекта:

```bash
python -m pip install -e ".[test]"
python -m pytest -q tests/test_ellipsis_invariants_02513.py tests/test_ellipsis_canonical_02513.py tests/test_ellipsis_recovery_0257.py
```

В Windows тот же набор запускает `run_formalization_tests.bat`.
Живой корпус остаётся доступен через существующую кнопку **M1: ellipsis acceptance** (100 случаев).

## Граница результата

Это проверенный срез формализации, а не заявление о полном закрытии М1/М2.
Использованы исходные архитектурные ограничения: deterministic-first, bounded semantic probes, atomic integration, scope-aware premises.
Новые тесты integration/вывода начинают с контролируемого результата узкого выделения ролей. Они проверяют переход recovery → canonical AH → proof gate, а не качество ответов живой LLM.
Отдельные тесты строят граф клауз на реальной pymorphy3 без подмены морфологии.

Последний доступный живой результат: **25/100 semantic PASS**, **89 runtime OK**, **11 runtime ERROR** в `20260907_000020_+0300(1).zip`.
Нового живого прогона модели здесь нет. Подробный разбор и оставшийся объём — `docs/ACCEPTANCE_REVIEW_02513.md`.
