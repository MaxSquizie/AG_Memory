# Modal / attitude formalization acceptance v1

18 EXACT cases for the architecture's limited modal/attitude contract.

Coverage:
- sentence-level POSSIBLE and its interaction with NOT / AND / OR;
- local versus whole modal scope;
- impersonal one-place REQUIRED / PERMITTED shells;
- negative non-modal adverbs that must not become modal operators;
- subject-bearing reported/belief/hope/desire content;
- factive contrast.

This suite does **not** introduce K/T/S4/S5 or probabilistic modal inference.
The required invariant is scope protection: asserting M(P) does not assert P.
Subject-bearing attitudes stay ordinary proposition-valued matrix N nodes so the
attitude holder is preserved. Impersonal one-place modal shells may be consumed
into canonical g_MODAL(P).

No keyword list authorizes modality. Morphology/source structure only opens a
bounded semantic probe. Operator and scope are fixed-choice decisions over
Python-supplied candidates.
