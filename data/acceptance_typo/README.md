# M1 typo/noise acceptance

81 scenario-isolated cases for Lexical Recovery before semantic formalization. The suite covers all four edit operations, keyboard neighbours, ё/е, inflection, short/long words, semantic roles, inversion, ellipsis, multiple errors, protected names/terms/acronyms/codes, rare exact words, and fail-closed ambiguity.

Run through the GUI button `M1: typo/noise acceptance` or pass these cases/oracle to `semantic-acceptance`.
