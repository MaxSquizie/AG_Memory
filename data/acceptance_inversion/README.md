# M1 inversion acceptance

Dedicated 100-case suite for syntactic inversion / constituent scrambling.

Coverage:
- object fronting and subject-final order;
- recipient/object scrambling;
- LOCATION scrambling;
- TOOL / MATERIAL / SOURCE scrambling;
- TIME / DURATION scrambling;
- predicate-initial marked order;
- multi-actant permutations;
- coordination under inversion.

The suite intentionally keeps punctuation grammatical so inversion is measured independently.
Use `acceptance_ellipsis` for inversion+ellipsis interactions and punctuation-noise cases.
