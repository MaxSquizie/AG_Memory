# Дневник: описание пропущенного субъекта

Проверена целая запись за 27 июля на реальном runtime и canonical store. Ресурсы — TEST_ONLY_COMPONENTS; короткие закрытые пробы исполнял независимый агент, которому передавались только запросы. Он не строил граф и не читал ожидаемые результаты. Наборы тестов не запускались, тестовые файлы не добавлялись.

Исходный файл: `Дневник_Николая_II.txt`, SHA256 `e1f39d7f418121ce5956be9410f058a14ef76f82c88a113df42570f5511d8e71`. Диапазон в декодированном тексте: `[94447,94814)`, 367 символов. Автор и год из имени файла не извлекались.

> Двадцать седьмого июля. Среда
> После доклада поехал с Алексеем встречать Аликс и дочерей, прибывших в двенадцать часов тридцать минут. Завтракали одни семейно. В два часа тридцать минут отправился на прогулку в лес за архиерейской церковью. После чая принял генерала Рузского, который снова назначается главнокомандующим Северным фронтом Обедал и провел вечер с Аликс.

## Что исправлено

До изменения (`fbd6fe5890f6f74c67760fbb46bdc9a51015269e`) прогон закончился RESOLUTION_ONLY, без коммита смысловых фрагментов. Для «Завтракали одни семейно» генератор не умел присоединить «одни» к пропущенному субъекту: описание искало только явную именную голову.

Добавлен общий кандидат согласованного описания уже лицензированного неявного субъекта. Условия — целое ADJF-чтение в именительном падеже, совместимые признаки и существующий SUBJECT_AGREEMENT-слот глагола. Обязательная закрытая проба выбирает связь или оставляет её нерешённой. Частных условий для слов дневника, новых лексических записей и автоматического выбора первого участника нет.

Слот принадлежит глаголу. Описание содержит ссылку на него и использует то же разрешение участника. T5 материализует существующий тип NOMINAL UsageLink, а не отдельный механизм памяти.

## Фактический результат

После изменения вся запись снова подана одним наблюдением. Получен APPLIED **одного** верхнего фрагмента — «Завтракали одни семейно». Это не означает, что вся запись формализована.

| Проверка | Результат в памяти |
|---|---|
| Неявный субъект | Один M типа GROUP, состав UNKNOWN, минимум два участника |
| «Завтракали» и «одни» | Одинаковый SUBJECT; один implicit gap и один IdentityBinding |
| Описание «одни» | NOMINAL-связь на этом M; собственной root-опоры нет |
| «семейно» | Открытый модификатор с proposition-аргументом «завтракали» |
| Смысловая идентичность | Все три T/N остаются OPEN/UNLINKED; числовое значение 1 или известное понятие не подставлено |
| Truth-support | Одна root-опора у целого модифицированного фрагмента; внутренние N доступны структурно |
| Дата | Одно EXISTENTIAL-свидетельство с CALENDAR_SCOPE: 27 июля, год неизвестен |

Группа не объявлена автором с конкретными родственниками: предыдущая фраза ещё не разобрана, положительного основания для её состава в этом прогоне нет. Внутренний «завтракали» не получил отдельного фактивного вывода из неизвестного смысла «семейно». Структурная запись сохранена; каноническая лексическая семантика этим не доказана.

Пять проб, из них одна новая — выбор композиции с описанием неявного участника. Ресурсный снимок до и после одинаков: `656ad2fd5ee6b4549dd03259171023167731734432d3ea4d04e4ef328b8f94eb`.

Native replay: вызовы 5→5, тики Ignition 62→62, ledger, batch_hash и committed_fragments совпали. Дополнительно журнал загружен в новую AH: состояние совпало. На двух копиях журнала отозваны соответственно implicit binding и целое наблюдение: все три N теряют F/S-видимость; восстановление каждой копии даёт то же состояние. Это проверки фактически полученного графа, не отдельный синтетический корпус.

## Что осталось в этой записи

1. Первое предложение не получает готовых frames. Ранний выбор ветки координации видит «и», а её текущий контракт отвергает смешение с AFTER «После». Далее нужны раздельные области для именной группы, инфинитива «встречать» и причастной области «прибывших…»; назначать одному событию все роли нельзя.
2. «В лес» остаётся между присоединением к движению и к «прогулке». Независимая проба вернула `?`; коммит этого предложения не разрешён. Следующая работа должна сохранять связи установленных поддеревьев и уточнять остаток, а не выбирать удобный ответ вручную.
3. Последнее предложение также не получает готовых frames: относительная область «который…» и новое «Обедал» без точки требуют корректного композиционного разреза. Сейчас общая ветка координации не справляется со смешанной областью.

Диагностики отвергнутых альтернатив сохранены; их количество не равно числу потерянных предложений. Состояние EXECUTED означает завершение runner, APPLIED — коммит разрешённого фрагмента. Ни одно из этих обозначений не означает полной семантической формализации дневника.
