# Связь v0.25.16 с последним acceptance

Входные живые измерения остаются прежними: ellipsis 63/100 (86 runtime OK), adversarial 17/36 (36 runtime OK), общий набор 173/200 (197 runtime OK). Архив-источник: acceptance_runs_m1_adversarial(5).zip. Новый живой запуск v0.25.16 не выполнен.

Текущие изменения направлены на классы ошибок, а не на номера примеров:

- Лишние номинальные утверждения вместо актантов эллиптической рамки — сопоставление событийных слотов перенесено перед PP attachment. Прямые примеры из входной диагностики — locative/material рамки, в том числе adversarial 26/28 и ellipsis 10/21; проверки расширены другими словами и перестановками.
- Перепутанные роли в параллельных рамках — общая процедура учитывает синкретичные падежные формы, но при конкуренции не выбирает первый вариант.
- Ложная дискурсивная ссылка на целую именную группу — признаки головы отделены от признаков владельца. Дополнительно закрыто небезопасное связывание грамматически несовместимого владельца.
- Чрезмерная locative эвристика — устранена независимо от того, улучшает ли её удаление конкретный oracle.

Оставшиеся направления: временной якорь относительного времени, точка с запятой/границы предложений при эллипсисе, несколько исходных/вложенных рамок, общая кореференция и уточнения, отдельные вложенные статусы и семантика связей относительно oracle. Эти классы не объявляются закрытыми по результатам offline pytest.

Обработка опечаток отложена по прямому указанию пользователя. Метрики и oracle не редактировались; шумовые случаи не исключены из знаменателя.
