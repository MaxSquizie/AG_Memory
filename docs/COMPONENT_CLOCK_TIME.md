# Количественное clock-выражение в дереве областей

Дополнение V7 §4.7 / §6.3. Грамматика, значения числительных и формы единиц
поставляются ресурсами. Модель выбирает прикрепление готовой структуры короткой
пробой; не генерирует часы, дату, JSON или подграф.

## Разбор и неизвестный якорь

`TemporalRules.kind=WORD_CLOCK` задаёт `pattern` с именованными группами
`hour`/`minute`, `number_values`, `clock_cycle=12|24`, `rule_id` и необязательный
`day_offset`. Имена групп могут быть заменены `hour_group`/`minute_group`.
Ресурс закрепляет словоформы числительных, вводящий предлог и формы единиц.
Лоадер проверяет схему, группы regex, целочисленные значения и clock_cycle.

Общий конструктор числа допускает одну атомарную величину либо десятки + единицы;
он не знает русского списка слов. Цифровая запись разбирается как число.
Неверные сочетания, часы вне 0–23, минуты вне 0–59 —
`TEMPORAL_EXPRESSION_INVALID`; исправление по догадке запрещено.
Длительность без вводящей clock-конструкции не получает clock-интерпретации.
Две clock-конструкции или конкурирующее временное правило требуют решения scope.

При `clock_cycle=12` значения 1–12 сохраняют обе реализации в 24-часовом круге.
Например, 2:45 даёт часы `[2,14]`; время запуска и положение фразы в абзаце не
выбирают один из них. Явные 0 и 13–23 имеют единственное чтение. При `24` час
однозначен по контракту ресурса. Неизвестный день/timezone или неоднозначный час
оставляют выражение символическим. Для точного timestamp нужны объявленный
якорь, зона/смещение и единственный час; неоднозначное гражданское время тоже
не конвертируется произвольно.

## Долговечное представление

`TemporalExpression {expr_id, kind=CLOCK, raw, source_range,
hour_candidates[], minute, anchor?, timezone?, status=SYMBOLIC|RESOLVED,
resource_sha256, rule_id}` сохраняет исходное содержание и основание разбора.
`source_range` — абсолютные символьные границы внутри наблюдения.

Выражение является датировкой, даже если абсолютная область неизвестна.
При известной структуре ASSERTED-клаузы и символическом clock T5 записывает
обычную пару SupportRecord + TimeAssertion в общей транзакции T6:

- `region=EXISTENTIAL(lo=UNKNOWN, hi=UNKNOWN, points=[])`;
- `temporal_expressions[]` содержит неизменяемое выражение;
- `REFERENCE_UNKNOWN` / `REFERENCE_AMBIGUOUS` остаётся диагностикой;
- абсолютная дата не создаётся, TimeAssertion не заменяется недатированной опорой.

UNKNOWN здесь — неизвестные границы, **не** бесконечный интервал и не TRUE для
любого момента. Дата не вычисляется из имени файла/часов компьютера. На write
boundary проверяются диапазон исходного выражения, числа, статус и согласованность
с region: SYMBOLIC требует неизвестной EXISTENTIAL-области; RESOLVED — POINT.

При неизвестных границах прежняя временная алгебра возвращает UNKNOWN для
точечного/ограниченного экзистенциального запроса и отказывает в лицензии
датированного вывода. Смешанную пару нельзя превратить в недатированную
пропозиционную элиминацию. Одинаковое написание двух clock-выражений не доказывает
одновременность. Чисто пропозиционный ответ использует видимость полной
утверждённой структуры, как и для остальных dated-фактов.

Новый независимый журнал/писатель не вводится. Expr находится в payload
ADD_TIME_ASSERTION, записывается атомарно с опорой и маркером; recovery и отзыв
работают с этой же записью. Разрешение якоря впоследствии требует объявленной
переинтерпретации/нового свидетельства; старый payload не переписывается.

## Композиция

Clock-диапазон учитывается до перебора именных ролей: «часа» и «минут» не
становятся случайными субъектами действия. При выборе полного bundle проба
видит и модификатор, и исходную clock-фразу, прикреплённую к этой клаузе.
Само наличие морфологического VERB-чтения у одного из токенов времени не
отбрасывает остальные предикативные альтернативы.

Направление пока является обычным OPEN-лексическим модификатором над событием.
Его фактивность не угадывается; структурная доступность внутреннего события
не равна отдельной truth-support. Scope над несколькими конъюнктами, AM/PM-
уточнения, дробные часы, длительности и произвольные количественные группы
не объявляются покрытыми этим конструктором.

Модули: `clock_expressions.py`; ресурсный словарь диагностического запуска —
`tools/formalizer_clock_fixture.py`. Флаг `--clock-time` включает TEST_ONLY
ресурс, а не production-словарь. Прогон не является PASS ворот.
