# Качественная предикация и лексические модификаторы

Дополнение V7 §4.7. Программа перечисляет структуры, модель отвечает коротким
выбором. Примеры иллюстрируют общую грамматику; имён и фраз источника в алгоритме нет.

## Кандидаты целой клаузы

Наличие VERB среди морфологических вариантов токена не доказывает существование
отдельного предикативного центра. COMPONENTS_V1 рассматривает альтернативы целой
клаузы, включая качественный предикат при выпущенном `quality_predicate_pos`.
Для ADJF требуется номинативное предикативное чтение; субъект согласуется с
предикатом. Отсутствие субъекта прилагательного не создаёт анонимного человека.

Выпущенные `copula_lemmas` разрешают учесть совместимый целый VERB-вариант как
связку качественного предиката. Ссылка и морфология связки сохраняются в IR.
Самостоятельное событие связки не утверждается; прошедшее время глагола не
создаёт календарный TimeAssertion. Неподдержанная связка остаётся непокрытой.

Все варианты сохраняют исходные ID и диапазоны. Полная альтернатива должна
покрыть все содержательные токены и обязательные роли. Неполные варианты
остаются адресными, но не выдаются за полную структуру. Лимит `max_candidates` ограничивает полностью построенные варианты закрытой
пробы, а не число сохранённых неполных разборов. Обрыв перебора хотя бы одного
предикативного якоря или превышение лимита полных вариантов — SEARCH_INCOMPLETE,
не выбор первого и не разрешение выбрать оставшийся префикс. Проба выбирает целый bundle: корень и все
его дочерние фреймы. Clarification применяет тот же выбор ко всему bundle.

## Область действия неизвестного модификатора

Выпущенный `modifier_content_role` задаёт типизированный слот для proposition.
Конструктор ADVB строит внешний лексический N с Ref(N|G) на внутреннюю клаузу.
Для неканонизированного значения создаётся occurrence-local OPEN/UNLINKED T,
а не именованный логический оператор. UsageLink имеет ATTITUDE=UNKNOWN.

Например, `почти(ушёл(M))` утверждает полное высказанное содержание; внутреннее
`ушёл(M)` только S-accessible, без собственной O-опоры. То же безопасное правило
действует для других неизвестных модификаторов: фактивность не угадывается.
Известный смысл проходит R-S/R-V/TemplateMap; сломанный known mapping нельзя
обойти созданием open T. Это структурная формализация с сохранением неизвестного
лексического значения, а не доказательство полного семантического понимания.

Опциональный `preposition_nominal_role` добавляет сущностный слот к такому N.
PREP + NOUN/NPRO связывает внутреннюю клаузу и именной аргумент, сохраняя форму
предлога. Роли сущности и proposition различны и проверяются лоадером.
Это не автоматическое присвоение LOCATION/TOOL по предлогу. Такой модификатор
может быть конъюнктом AND; тогда только внешний N получает AND_ELIMINATION,
внутреннее событие не получает опору через модификатор.

Начальная реализация требует одного однозначного лексического модификатора
либо простой двухтокенной предложной группы с однозначной целой морфологией.
Неопределённое вложение нескольких модификаторов, их область над несколькими
конъюнктами, сложная количественная группа и вложенный относительный временной
якорь сохраняют отказ. Их нельзя отбросить ради положительного коммита.

## Ссылки на одного анонимного участника

Проба называет целевую клаузу, исходный диапазон, предикат, роль и её целые
морфологические признаки. Контекст абзаца не заменяет адрес целевого пропуска.
Вопрос прикрепления модификатора не включает правила хранения опор/фактивности:
это другая проверка, а не альтернативное прочтение исходной фразы.

Кандидаты CHAIN остаются замороженными и адресными. Если короткая проба выбрала
несколько ссылок, уже разрешённых в **один и тот же entity_ref**, это один
участник с несколькими основаниями, а не конкурирующие люди. D-проверка равенства
выбирает детерминированного представителя для связывания; raw MULTIPLE_ADMISSIBLE,
все выбранные ID и доказательство равенства сохраняются в Decision/history.

Разные entity_ref, неразрешённая цепочка или ответ «недостаточно контекста»
не сворачиваются. Совпадение написания, пола или числа не является равенством.
Сущности из отвергнутых альтернатив разбора не попадают в следующий список
референции как установленные участники.

## Граница runtime

T5/T6 — прежний единственный канал world-записи. После native receipt нельзя
запускать legacy TemplateCompletion над сокращённой UI-проекцией. Вложенная
proposition не проецируется как плоский предикат с потерянным аргументом:
граф читается из native receipt/store, диагностика отмечает владение scope.
Replay и отзыв проходят обычный журнал, без повторного генератора шаблонов.

Модули: `component_predication.py`, `component_modifiers.py`,
`component_prepositions.py`; прежние clause/coordination/participants и native
планировщик сохраняют свои границы. Политика требует нового resource release.
TEST_ONLY-прогон не повышает production coverage или статусы G0–G5.
