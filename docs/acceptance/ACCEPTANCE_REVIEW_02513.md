## Остаток работы

- 87–92: эллипсис через `;` и границу предложений. Межпредложенческий antecedent contract требует отдельной реализации; текущая версия не расширяет его произвольным поиском назад.
- 93–96: восстановление вложенных/control-фреймов. Если одна клауза содержит несколько источников, текущий код явно отказывает вместо произвольного выбора. Нужен перенос структуры вложенного фрейма с сохранением scope.
- 97–98: несколько предикатов + coreference + эллипсис. Выбор актуального фрейма внутри клаузы остаётся отдельной задачей.
- 99: инверсия `а журнал — Мария` пересекается с nominal predication; нельзя решать её только положением тире.
- 100: опечатка в исходном объекте должна разрешаться существующим bounded lexical recovery.
- TIME/LOCATION/DURATION и более богатые составные реализации ролей требуют живой проверки. Ошибки временного anchor в 18, 67, 69 нельзя устранять подстановкой произвольной даты.
