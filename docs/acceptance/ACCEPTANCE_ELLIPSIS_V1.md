# Ellipsis Acceptance v1

Новый отдельный acceptance-корпус для проверки восстановления скрытой структуры.

Корпус не смешивается с M1 adversarial:
- M1 adversarial: шум, инверсия, базовые случаи;
- Ellipsis v1: discourse reconstruction.

Классы:
- predicate ellipsis;
- role-frame inheritance;
- proposition negation;
- proposition confirmation;
- temporal inheritance;
- scope boundary;
- coreference boundary;
- ambiguity preservation.

Цель: определить место потери информации до реализации resolver.
