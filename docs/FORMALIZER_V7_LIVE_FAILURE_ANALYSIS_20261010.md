## Проверка границ

Все 51 сохранённый ответ повторно подан неизменённым в реальный конвейер через offline backend; новые запросы к локальной модели не выполнялись. Внешний comparator использовал исходный gold, который backend не получает.

Результат на тех же ответах: **11 PASS / 40 FAIL**. Изменились только A31/A33 после исправления пунктуации. Новая схема отклоняет все 31 записанный ответ с ошибочными head/role; строгий валидатор их также отклоняет. Это проверка исправлений на записанных данных, а не новый live-результат модели.

**105 focused-проверок прошли.** Они охватывают schema/validator, запрет чужих якорей и неизвестных полей, пунктуацию и действительно непокрытые слова, resource integrity, декларации INFN, отдельные STATE/TRANSITION, дефисную токенизацию, частичные отчёты, transport и реальный GUI writer/QProcess.

Для нового live-прогона нужен новый пустой каталог. Replay старого запуска после смены хешей исходников/ресурсов по штатному контракту запрещён. G0–G5 и подписанный production release этими исправлениями не подтверждаются.
