## Изменение поведения

Предложная группа допускается в роль KNOWN-предиката при совпадении предлога,
падежа и R-V. Без ресурса остаётся незакрытой. Имя сущности не включает предлог.
Морфологическая неоднозначность предлога требует положительной закрытой пробы.
T3 повторно сверяет привязку с конкретной валентностью: другая беспредложная
роль с тем же именем не принимается. Модель не строит граф.

Обязательный непокрытый объект теперь оставляет вопрос `MISSING_REQUIRED_ROLE`
и заблокированный кандидат вместо удаления всей клаузы. Автоматического нового
объекта или fallback known→open нет.

механик, не качества модели и не лексического покрытия.
