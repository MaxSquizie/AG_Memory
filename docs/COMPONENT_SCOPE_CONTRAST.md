# Короткая проба по различающимся связям

Дополнение V7 §4.7. После программного построения полных кандидатов модель
может получать только различающиеся связи области, если остальное содержание
кандидатов доказуемо одинаково. Это сокращение представления вопроса,
а не раннее удаление альтернатив и не генерация графа моделью.

## Условие проекции

`component_scope_contrast.contrast` нормализует локальные frame/gap ID по
исходным якорям и ролям. При неоднозначном соответствии якорей проекция
отклоняется. Все поля FrameCandidate, включая неизвестные конструктору поля,
морфологию, актанты и именные описания, остаются в сравнении.

Из сравнения отдельно выделяются только proposition-ребра с frame_ref и
attitude и соответствующие ссылки MODIFIER_SCOPE/component_child. Последние
сначала сверяются с реальными рёбрами. Другие формы содержимого не скрываются.
Если нормализованные основы различаются, применяется обычная полная подпись.

При одинаковой основе выделяется пересечение рёбер. Проба получает отличия
каждого кандидата: исходный якорь родителя и ребёнка, роль и attitude.
Требуются разные наборы рёбер и от одной до четырёх отличающихся связей на
вариант; иначе остаётся полная подпись. Коммутативность лексических
модификаторов не предполагается. `LOCAL_SCOPE_CONTRAST` сохраняет хеш общей
основы, все рёбра каждого candidate_id и ID общих рёбер.

Список candidate_id, порядок вариантов и последующая материализация не
меняются. Одинаковое имя/описание метки печатается один раз; отображение
ответа в исходные ID сохраняется в запросе и durable replay.

## Основание выбора

Общая инструкция component-проб различает сгенерированную возможность и
положительное основание в исходном тексте/доступном контексте. Несколько
ответов требуют основания для каждого. Недостаток контекста даёт `?`;
выбирать первый или выдумывать личность/факт запрещено. Эта инструкция не
меняет обработчик исходов: неоднозначность и UNKNOWN блокируют фрагмент.

Проба получает исходный текст. Компактная подпись не заменяет контекст и не
объявляет семантическую эквивалентность различных деревьев. Качество выбора
локальной моделью требует отдельного фактического прогона.
