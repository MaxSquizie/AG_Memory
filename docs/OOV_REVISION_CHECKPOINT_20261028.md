# Незавершённый прогон: исправление контрактов

Источник: «Я попросил Диму зафлюмить квендрик но он сказал что квендрик не работает и попросил меня подождать.»

Запись ещё не достигнута. Изменения не опубликованы; последний опубликованный temp — 6515de5.

Изменения общего алгоритма:

- PartitionDomain сохраняет подтверждённые функции вхождений и владельца CONTENT при локальном ремонте границ. Явный пересмотр функции после исчерпания ограниченного поиска отзывает зависимые решения и подписывает новый результат на сохранённые доказательства.
- Владелец CONTENT выбирается до границ содержания. Его собственное вхождение остаётся в родителе. При нескольких конструкциях вопрос задаёт порядок обхода по исходному тексту, не отрицает остальные конструкции.
- Вопросы о связках CONTENT различают родительскую часть и зависимое содержание конкретного владельца. Проверка разделения явно показывает применяемое отношение.
- При достраивании разрывного множества выбранные слова показываются в исходном порядке.
- Дочерние области получают контекст по родительской цепочке независимо от алгоритма их создания. Контекст не расширяет selectable TARGET; идентичный TARGET не дублируется.
- Некорректный формат ответа допускает один явно записанный запрос исправления с тем же доменом и исходным ошибочным ответом. Декодер остаётся строгим. Ответы 0, ?, несколько альтернатив не переспрашиваются. Бюджет и предел длины соблюдаются.

Проверки: check_partition_function_revision.py прошёл после последней правки контекста; check_selection_format_repair.py прошёл. check_conversation_write.py и check_conditional_write.py прошли после перехода к owner-first, до изменения контекста. Это сценарные проверки, не доказательство поведения живой модели. Старые сценарии Script механически переставляют тот же заданный owner перед границами; семантические ожидания не менялись.

Живые ответы: только изолированные gpt-6-luna low. В актуальном прогоне CONTENT «сказал» содержит «квендрик не работает», в родителе остаётся вторая просьба. Ответ 98 вместо номера строки был отвергнут; на явно адресованный запрос исправления получен 6. На родительской части Luna дважды выбрала LEXICAL; дальнейшая сборка выделила инфинитив и сочинение.
