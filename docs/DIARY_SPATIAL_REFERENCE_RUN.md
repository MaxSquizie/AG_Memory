# Дневник: «вверх» и последующее «там»

## Результат

На исходной записи дневника получена типизированная пространственная привязка: одно M относительного места назначения, исходный SPATIAL_ANCHOR для «вверх» и зависимый SPATIAL_REFERENCE для «там». Координат, названия географического места и абсолютной высоты нет.

Источник, диапазон `[99690,99841)`:

> Десятого августа. Среда
> День простоял хороший. Прогулку совершили вверх. Там катались на шлюпках и гуляли. После чая принял Шуваева. Вечером занимался.

SHA256 полного исходного файла: `e1f39d7f418121ce5956be9410f058a14ef76f82c88a113df42570f5511d8e71`.

Новый контракт описан в [RELATIVE_PLACE_REFERENCES.md](RELATIVE_PLACE_REFERENCES.md), согласован с архитектурой и [контекстом областей](DOCUMENT_CONTEXT_AREAS.md). Реализован в небольших отдельных модулях; существующие стадии, M, IdentityBinding и каскад отзыва сохранены.

## Фактическая память

- `M:place:d298cefa2f0d4316b972e9a3f940b770a83e34e1f08a4da60ac27540536c8e56` хранит исходный якорь `[66,71)`, raw=«вверх», location_kind=DESTINATION, coordinates_status=UNKNOWN.
- Узел RELATIVE_UP_DESTINATION связывает описанное движение с этим M.
- Узел RELATIVE_AT_PLACE использует тот же M и содержит выбранную группу «катались на шлюпках и гуляли». «Там» не стало отдельным несвязанным местом или синонимом направления.
- Пространственная ссылка имеет один decision_ref на исходное упоминание. Локальная и поднятая на координацию структуры используют одно решение; повторной LLM-пробы о том же референте нет.
- Календарная область записи и символическое вечернее свидетельство сохранены без числовых границ времени.

Receipt: APPLIED, пять верхнеуровневых фрагментов, 71 операция. В receipt остаются STRUCTURAL_OPERAND_UNRESOLVED для трёх альтернатив — они приведены в evidence. APPLIED не заявляет полной семантической формализации всех содержимых структурных операндов или всего дневника.

## Проверка на полученном графе

| Действие | Фактический результат |
|---|---|
| Повтор того же запуска | Ledger и batch_hash прежние; вызовы остаются 12, тики Ignition — 42 |
| Отзыв исходной привязки места | Оба spatial binding INVALID; две зависимые пространственные вершины теряют F-видимость; четыре независимых заключения сохраняются |
| Отзыв только опоры исходного движения | Исходное утверждение теряет видимость; spatial binding и последующее утверждение с «там» остаются живы: упоминание места не отозвано |
| Отзыв наблюдения целиком | F/S-видимость пуста, обе привязки инвалидированы |
| Восстановление свежего store после каждого из трёх отзывов | Совпадение canonical ledger во всех ветках |

Это три операции над копиями реально полученного журнала, а не добавленный набор синтетических тестов. Новые тестовые файлы не создавались, test suite не запускался.

## Воспроизводимость и ограничения

Ресурс **TEST_ONLY**: `656ad2fd5ee6b4549dd03259171023167731734432d3ea4d04e4ef328b8f94eb`. Лексические записи пространственных смыслов находятся в fixture, русских слов-исключений в runtime нет. Production reviewed release не объявлен.

Первичный живой прогон использовал независимого агента для закрытых проб. После устранения дублированного вопроса окончательный прогон перенёс 11 ответов только при полном совпадении байтов запросов; новый двенадцатый вопрос отдельно получил ответ агента. Локальная модель не использовалась. Этот перенос транспорта отделён от проверенного native run replay: последний не вызывает провайдера и не добавляет тики.

Запросы, ответы, транспортное происхождение, полные привязки/пространственные узлы, временные свидетельства, receipt, статусы после отзывов и хеши изменённых runtime-файлов: [evidence/diary_spatial_reference.json](evidence/diary_spatial_reference.json).

Текущий механизм читает предшествующие пространственные якоря того же наблюдения внутри ограниченного контекста. Пространственные ссылки через долговременную память должны идти через типизированный Ignition-read; этого расширения пока нет. Не заявлены также полный охват многозначности пространственной лексики, произвольных предложных мест и референции через цитаты. G0 и другие ворота не пересматривались.
