2. 17 binary lexical-identity failures caused by positional bias in mirrored A/B decisions (`Петра/Пётр`, `Анне/Анна`, `полка/полк`, `стоить/стоять`, `ваз/ваза`).

## Fixes in this slice

### Probe protocol

- Numeric predicate/actant span probes request a bare integer without brackets or punctuation.
- Numeric selection generation budget is sufficient for signed stop options.

### Lexical identity

- Mirrored A/B remains the first lexical ambiguity probe.
- If the two orientations expose positional bias, one position-free literal-lemma fallback is allowed.
- The fallback is accepted only when the literal output exactly matches one of the same two deterministic morphology candidates; any third value fails closed.
- No likelihood scorer or choice margin is used.

### Negation and ABSENTEE

- Role prompts explicitly separate proposition/contrast negation from participant role.
- `не` never by itself changes SUBJECT/OBJECT/etc. to ABSENTEE.
- ABSENTEE is reserved for a target explicitly represented as absent/excluded/non-participating.

### Parent/child frame relation

- Removed ordered first-positive probing (`CONTENT?`, then `PURPOSE?`, ...).
- After ClauseFrameGraph orientation, the model makes one bounded exact-label comparison over all structurally admissible relations:
  `CONTENT_LINK / GOAL_LINK / CAUSE_LINK / TIME_LINK / PLACE_LINK / SOURCE_LINK / MANNER_LINK / SEPARATE`.
- Surface subordinators remain evidence only and do not assign canonical roles.

### Non-finite frame hierarchy

- Non-coordinated infinitives can form dependency chains.
- `Анна хочет попросить Петра прийти` now orients `WANT -> ASK -> COME`.
- Coordinated infinitives remain siblings: `хочет купить и прочитать` orients `WANT -> BUY` and `WANT -> READ`.
- Fronted non-finite frames still attach to a later finite matrix when no preceding governor exists.

### Relative clauses

- Relative semantic-role decision is grounded in the antecedent entity as well as the relative surface form.
- This prevents a weak model from treating `которого` itself as the semantic participant instead of resolving the role of `Человек` in `Мария встретила ...`.

### Copular holder

- After an adjectival/predicative copular STATE is structurally proven, one unambiguous agreeing nominal is deterministically its semantic holder/SUBJECT.
- This is a narrow rule and does not restore generic `NOM -> SUBJECT`.
- Participial/passive complements stay on the passive path.

### Acceptance oracle

- Proposition-valued children referenced through `OBJECT`, `PURPOSE`, or `HOW-TO` are now expected as `EMBEDDED` unless already `CONDITIONAL`.
- Canonical oracle checks verify `semantic_scope=EMBEDDED`.
- Causal and temporal subordinate facts remain ASSERTED.
- 24 broad200 assertion expectations and 5 regression40 expectations were updated.
