## Почему это не case patch

Алгоритм не читает номер сценария и не содержит его участников, предикаты или
объекты. Для temporal relation используются topology proposition graph,
ellipsis-family membership и число независимых roots. Для nonfinite scope модель
решает один bounded source-only вопрос между четырьмя семантическими режимами;
никакой matrix-lemma table нет.

Новые тесты используют другой словарь и включают контрпример: TIME после
predicate обязан сохраниться. Это не позволяет исправлению превратиться в общее
удаление sequencing words.

## Ожидаемая граница следующего живого запуска

Два неорфографических failure-класса закрыты в исполняемом пути и регрессиях.
Фактический новый score появится только после запуска той же пользовательской
модели. Орфографический case остаётся в знаменателе и не переоценивается вручную.
