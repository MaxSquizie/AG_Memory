# Пунктуация на четвёртой десятке Russian-GSD

Взяты подряд test-s32–test-s41 тестового раздела Russian-GSD 2.15. Каждая подача проходит через обычный `ah.russian_grammar.memory.submit` со свежей памятью. Исходная версия — [b8591a4](https://github.com/MaxSquizie/AG_Memory/commit/b8591a477af716b83b3e3a526c39c324911bc5db). На ней из 30 подач 26 остались неразобранными и четыре привели к неверной записи. В трёх вариантах s36 «2005» потеряло связь со словом «году». В s38 без кавычек слово «волость» оказалось при глаголе «входит».

## Результат контрольного выбора

| Подача | До изменений | После изменений | Вопросов на десять предложений |
|---|---:|---:|---:|
| Исходная | 0/10 | 10/10 | 24 |
| Без знаков | 0/10 | 10/10 | 24 |
| С лишней запятой | 0/10 | 10/10 | 34 |

Все 30 контролируемых подач сохранили наблюдения. Во всех 20 изменённых вариантах проекция графа совпала с исходной. В 27 подачах первая проба допускала «?» и «0». Каждый из этих ответов отдельно проверен на пустой памяти, ни одна запись не появилась. Три подачи разобрались без вопросов. Это исходный и беспунктуационный варианты s36 и беспунктуационный s39.

## Условия сравнения

1. Для исходного текста сохранены символы поля `text`, включая ударения и буквальное представление кавычек.
2. Для второго варианта удалены токены пунктуации и точка сокращения, сохранены буквы, ударения и числа. Экранированные кавычки удаляются целиком. «в XIX в.», например, превращается в «в XIX в».
3. Для третьего варианта добавлена одна запятая между соседними словами с прямой зависимостью в разметке. Позиция выбирается до запуска по тому же порядку отношений, что на предыдущей десятке. Внутри формализатора эталон недоступен.

Контрольный выбор проверяет, достижимо ли размеченное чтение. Среди вариантов сопоставляются роли, вершины зависимостей всех содержательных слов, смысловые ограничения и леммы. Для независимых от UD решений явно указано выбранное чтение, например «её папа» означает отца Хелен. Вопросы и ответы с указанием основания выбора сохранены для каждой подачи. Десятка использовалась при разработке. Результат такого выбора сам по себе не измеряет качество JEV.

## Что проверяется в памяти

Проверка сравнивает фактические вершины, ссылки и координаты слов записанного наблюдения с исходным текстом. Для сопоставления с UD разворачивается внутренняя связь через предлог. В «в начале» AG хранит сначала предлог, затем управляемое слово, UD считает вершиной существительное. При сравнении двух вариантов проверяются также леммы, морфология, количества, роли, области, указатели на участников и подтверждённые слова в области модификатора. Из проекции исключены знаки препинания и абсолютные координаты, которые меняются при удалении запятых. Исходные координаты каждого варианта проверяются отдельно. Разметка всех типов зависимостей LAS не оценивалась.

| № | Проверяемое место | Содержательное условие |
|---|---|---|
| 32 | «Заслуженный, деятель искусств Армянской ССР» | Самостоятельная именная группа не получает вымышленного носителя звания. Для «ССР» отдельно проверяется место его присоединения в цепочке родительных. |

| 34 | «в XIX, в.» | XIX обозначает девятнадцатый век. «Её» и «вещество» — объекты разных действий. «Так как» вводит причину второго действия, «оно» выступает основой. |
| 35 | «в спортивной, семье» | У «родилась», «был … тренером» и «играли» три разных подлежащих. Контрольное чтение «её папа» относится к Хелен. |
| 36 | «в 2005, году» | 2005 указывает год, 1467 задаёт количество людей. Первое число не становится участником события. |

| 38 | «сельского, поселения» | «Шелковская волость» — название поселения, «волость» зависит от «поселения». |

| 40 | «турецкую, атаку» | Действие «отразив» выполняют войска. 8 обозначает номер часа, «к» управляет редким существительным «ретраншаменту» с исходным написанием. |

## Независимые ответы без пунктуации

Изолированные читатели gpt-5.6-luna с низким уровнем рассуждения получали текущий фрагмент, вопрос и варианты ответа. У них не было доступа к корпусной разметке. Для девяти предложений совпали все проверяемые вершины и смысловые условия. Восемь воспроизвели всю проверяемую проекцию контрольного графа. Ответы повторно поданы через обычный вход с проверкой текста каждого вопроса, контекста и порядка вариантов. В серии были и повторные проверки после изменения формулировок.

- В s32 «Армянской ССР» читатель отнёс к «искусств», в корпусе — к «деятель». В память попало выбранное чтение.
- В s34 связи и область причины совпали, но для «больших» читатель выбрал лемму «больший». В контрольном чтении — «большой».
- В s35 ранний вопрос о том, от какого слова зависит «папа», дал выбор «был». Новая проба спрашивает, кем назван участник, и предлагает «баскетбольным тренером». Независимый читатель выбрал это сочетание, затем «её папа» и «Хелен». Полученный граф совпал с контрольным.

## Воспроизведение

Требуются тестовый файл Russian-GSD версии 2.15 и зависимости проекта. Скрипт сверяет SHA-256 корпуса. При контрольном отборе и при воздержании действует ограничение в 12 секунд процессорного времени на этап. При наличии пробы отдельно проверяется первая реакция на «0» и отсутствие записи. У детерминированной подачи нет ответа на пробу, который можно было бы подменить. Префикс запуска `PYTHONPATH` выбирает проверяемый код.

```bash
git worktree add --detach /tmp/ag-gsd-fourth-base b8591a477af716b83b3e3a526c39c324911bc5db
PYTHONPATH=/tmp/ag-gsd-fourth-base/src python scripts/audit_russian_grammar_fourth_ten.py "$corpus" /tmp/fourth-baseline.json
PYTHONPATH=src python scripts/audit_russian_grammar_fourth_ten.py "$corpus" /tmp/fourth-results.json --expect docs/evidence/russian_grammar_fourth_ten/results.json
```
