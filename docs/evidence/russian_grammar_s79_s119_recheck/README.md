# Двенадцать исходных предложений Russian-GSD и совместимость правил

Базовая версия — `40ace58`, корпус — Russian-GSD r2.15, тестовая часть. На сравнение поступает один и тот же исходный текст. Используются также варианты без пунктуации и с добавленной запятой вне имён. Для s109 последнего варианта нет. В каждой из 119 подач создаётся отдельная память. Подтверждение пробы берётся из записи изолированного читателя GPT-5.6 Luna, уровень рассуждения low. Эталон UD участвует в оценке после ответа и в генерации контрольной пунктуации.

У всех 80 прежде записывавшихся входов совпали последовательности проб, контрольные суммы графа и метаданных. В более ранней контрольной выборке совпали все 40 результатов. Для 23 записей сравнивались также метаданные слов. Ещё 17 остановились на одной и той же отсутствующей архивной пробе, поэтому вывод о совместимости для них ограничен этой точкой. Прошли 377 профильных тестов.

Из 11 новых записей на оригиналах шесть совпали с UD по проверяемым связям. У пяти разошлось по одной голове: «Порту» (s79), «посадил» (s85), «с» внутри «наряду с» (s93), «2002» в «в 2002 году» (s113) и «1647» (s119). В s85 дополнительно расходится токенизация имени. Входы с произвольной пунктуацией чувствительнее к выбору читателя: в s86 после добавления запятой оба названия отнесены к «мультфильма», в s104 запятая в «его, производных» меняет разбор притяжательной группы. Ни один из этих двух вариантов не засчитан как точное совпадение.

[До](before.json) и [после](after.json) содержат 119 попарных результатов. В [графах исходных предложений](graphs.json) головы и отсылки заданы индексами от нуля. Для s115 приведены связи фрагмента. [Протокол чтений](readings.json) содержит 168 новых карточек, использованных при сравнении. [Ранний контроль](legacy.json) хранит результаты второй проверки.

## Что проверяется

- Для записи проверяются позиции слов, головы, роли подлежащего и объекта, рёбра контроллеров и отсылок. Дополнительно сравниваются SHA-256 метаданных наблюдения и **всех полей каждого его слова**, включая морфологию, статус утверждения и привязки. Для отказов и именных фрагментов проверяется пустота памяти.
- Одинаковый синтаксический граф может кодировать разную область утверждения. В s114 отдельно проверено, что «рассчитывать» остаётся под действием «мог», а сведения об Уокере «жил» и «работал» при подтверждении читателем получают статус утверждения. В s93 получателем помощи и исполнителем обоих инфинитивов служит «ей».
- При разной токенизации дефисного имени сравниваются внешние связи целого слова. Непроверенные внутренние связи перечислены в `unchecked_name_internals` и исключают полное совпадение с UD.
- Для s115 принят именной фрагмент. Его связи доступны в разборе, событие в память не записывается. Для s81, s89 и s91 сохранены три ранее принятых пользователем чтения.

## Изменения на исходных предложениях

| Russian-GSD | Результат и проверенная связь |
|---|---|
| s79 | Две части соединены точкой с запятой. У «не сыграв» сохранились отрицание и исполнитель Агияр. Вторая часть различает получателя «Эштреле» и название клуба «Порту». |
| s85 | При «схватил» построен ряд участников с именами и приложениями. Подлежащее Аслан-паша доступно и для «посадил». Внутренние части дефисного имени отдельно не проверены. |
| s86, s111 | Названия в кавычках присоединяются к словам вне кавычек. В s86 «Шрек» и «Кот в сапогах» имеют разные определяемые слова. В s111 «РусГидро» относится к ОАО. |
| s93 | В «помогал ей расстаться … и … войти» получатель помощи выполняет оба действия. Для омонимичной формы «ей» читатель выбирает между вопросами «кому?» и «кем или чем?». |
| s104 | Родительная позиция в «изучение лепидена и его производных» позволяет сохранить незнакомое слово и привязать к нему притяжательное «его». |
| s110 | «Двенадцати песен» входит в группу «перевод». Относительное «который» служит дополнением «использовал» и отсылает к «перевод». Семён Липкин — исполнитель второго действия. |
| s112 | Эллиптическая часть «а через него — Гитлера и других …» сохраняет свои зависимости. Установлена отсылка «его культом» к Ницше. У «через него» конкретный референт остаётся открытым. |
| s113 | «Становился чемпионом» задаёт именную часть сказуемого с неизвестным участником. Каждый повтор «чемпионом» получает соответствующую дату или ряд лет. Уточнение о команде отнесено к 2003 году. У несклоняемого «ЧГК» зафиксирована связь с предлогом, различить падежи по форме здесь нельзя. |
| s114 | В «мог рассчитывать … на помощь Уокера, который также жил и работал неподалеку» проба разделяет возможное и утверждаемое. Область «мог» охватывает «рассчитывать». |
| s115 | У «Филькино Верхотурского уезда Екатеринбургской губернии в семье служащего» разбор сохраняет цепочку имён. Для «в семье» читатель указал связь с пропущенной частью. Запись о рождении или работе не создаётся. |
| s119 | Вложенная скобка о произношении связывает «Корней» с исходным именем. Для года в «член Французской академии (1647)» читатель выбрал «член». |

## Воспроизведение

Из корня проекта, после установки зависимостей и получения тестовой части корпуса:

```sh
dir=docs/evidence/russian_grammar_s79_s119_recheck
previous=docs/evidence/russian_grammar_s98_s120/readings.json
PYTHONHASHSEED=0 PYTHONPATH=src python scripts/audit_russian_grammar_readers.py ru_gsd-ud-test.conllu old_twenty.json --start 72 --readings "$previous" --readings "$dir/readings.json"
PYTHONHASHSEED=0 PYTHONPATH=src python scripts/audit_russian_grammar_readers.py ru_gsd-ud-test.conllu new_twenty.json --start 98 --readings "$previous" --readings "$dir/readings.json"
PYTHONHASHSEED=0 PYTHONPATH=src python scripts/replay_russian_grammar_legacy.py ru_gsd-ud-test.conllu legacy.json
```

Для сравнения с базой те же скрипты запускаются с `PYTHONPATH`, указывающим на `src` коммита `40ace58`. Лимит каждой подачи — 30 секунд процессорного времени. Для ранних выборок скрипт воспроизводит только однозначно зафиксированные ответы. Остановка на общей недостающей карточке подтверждает совпадение трассы до этой точки.
