# Russian-GSD r2.15 · тестовые предложения после s71

Первые 20 подходящих предложений после s71. Пропущены s72–75, s80 и s84. Отбор исключает токены с пометой Foreign=Yes или FW и буквы за пределами русского алфавита. Римские порядковые числа, русские заимствования и имена в кириллице проходят фильтр. Корпус помечает «АКВА» и «РИУ» как FW, поэтому s80 пропущен.

Каждый текст подан в отдельную пустую AG_Memory через штатный submit. Контрольные варианты удаляют токены пунктуации или вставляют запятую внутри синтаксической связи. Дефисы внутри исходного слова сохраняются. Изолированные читатели gpt-5.6-luna с низким уровнем рассуждения получали только отображаемый текст пробы. Для идентичной пробы повторно использован тот же ответ. Эталон используется при подготовке пунктуационных изменений и проверке графа. Рабочий формализатор его не получает.

Проверка сверяет исходные интервалы, сохранённый текст, рёбра графа, синтаксические вершины всех непунктуационных токенов в проекции UD и проверяемые роли подлежащего и прямого дополнения. Совпадение относится к этим критериям. Смысл, референция и полнота последующего поиска требуют собственных проверок.

### Что изменилось в разборе

- В s76 словарное вводное сочетание сохраняет конкурирующее буквальное чтение. Проба «Выберите „Как правило“, если это вводное замечание рассказчика ко всему сообщению» позволяет установить его роль. После подтверждения «как» внутри сочетания перестаёт открывать вопрос к памяти.
- В s81 римские числа перед существительным во множественном числе образуют порядковый интервал. Удаление тире требует подтверждения интервала. Для двух соседних обстоятельств с общим сказуемым допускается общая опора запятой, если все содержательные связи и области действия совпадают.
- В s83 дефисное определение допускает проверку согласования с «стиле», а «из Файюма» получает варианты привязки к причастию и к зависимому существительному.
- В s90 формализатор ищет границу препозитивной части с «чтобы» по совместимости инфинитивной группы и самостоятельного сказуемого. «С 1996 года» использует управление предлога и порядковое чтение числа. В s91 календарное уточнение после месяца сохраняется и в середине предложения. При согласовании следующего существительного с числом доступно количественное чтение.
- В s92 роль кратности строится из числительного, согласованной с ним единицы, засвидетельствованной в FrameBank, и связи с действием. «Один раз» сообщает число появлений алжирца. Сфера реализации — простая группа при одном подходящем сказуемом.
- В s93 предложная группа допускает чтение подтверждённого многословного имени. В сокращённой фразе «К Бынаты Хицау обращалась молодая невестка» появляется проба на имя целиком. Полное предложение остаётся без записи.
- В s94–s96 предложное управление сохраняет возможность присоединить родительное продолжение при омонимии. «С начала 1960-х» содержит порядковое числительное с подразумеваемым существительным. В s95 группа места может быть сказуемым при нулевой связке. Проба о предмете, которому приписано место, различает «села» и «пруд».
- В s97 для морфологически связанного с действительным причастием существительного формализатор проверяет управление исходного глагола. На пробу «Какое слово требует зависимой формы „фронтами“ в этом предложении?» читатель выбрал «командующие» из вариантов «шли» и «командующие».

### Где сохраняются расхождения

У исходного s81 формализатор хранит «в честь» как составной предлог, корпус разбирает «честь» как существительное. В s89 читатель отнёс «на один сезон» и «с московским „Спартаком“» к слову «контракт», а корпус привязывает их к «подписал». В s91 календарная привязка исправлена. Читатель связывает «что привело» с «привязан», корпус — с «объявил».

Есть и содержательная ошибка при повреждённом входе. В s76 вставка запятой между «боевых» и «вылетах» приводит к разбору «боевых» как фамилии. Правильное согласование через запятую не попадает в предложенные варианты. Эту запись приёмка отклоняет.

Для каждого несовпадения в results.json приведены поверхность слова, ожидаемый и фактический индексы управляющего слова. Нумерация начинается с единицы, ноль обозначает корень. Исходная версия для сравнения — 29d2787cae4b2a56276ea67b0b7475018a397f16. Ответы читателей и контрольные суммы сохранены рядом.

Для воспроизведения выполните команду из корня проекта с установленными зависимостями.

```sh
PYTHONPATH=src python scripts/audit_russian_grammar_readers.py /path/to/ru_gsd-ud-test.conllu result.json --readings docs/evidence/russian_grammar_s76_s97/readings.json
```
