# Расширение русского формализатора на test-s42–test-s51

Взяты десять последовательных предложений из тестовой части Russian-GSD 2.15. Каждое подано через `ah.russian_grammar.memory.submit` в исходном виде, без токенов пунктуации и с лишней запятой внутри грамматической связи. Текст корпуса, включая «Олипиаде», сохранён. Дефис внутри числовой пометы «24-11» входит в лексический токен корпуса и сохраняется в беспунктуационном варианте. Источник предложений — [UD Russian-GSD, CC BY-SA 4.0](https://universaldependencies.org/treebanks/ru_gsd/index.html).

| Подача | Совпали до правок | Совпали после правок | Число вопросов на десять предложений |
|---|---:|---:|---:|
| Исходная | 0/10 | 10/10 | 38 |
| Без пунктуации | 0/10 | 10/10 | 40 |
| С лишней запятой | 0/10 | 10/10 | 45 |

На [исходной версии](https://github.com/MaxSquizie/AG_Memory/commit/6f986fde2dd2cb474b6f683717556f60543a080e) четыре контрольные подачи привели к неверной записи. В двух случаях «диаметром» зависело от «касающуюся», и у причастия отсутствовала ссылка на носителя признака. Ещё в двух случаях «OS» становилось сказуемым, а «сегмент» — подлежащим.

## Что проверено в графе

| Пример | Содержательная проверка |
|---|---|
| 42 | В «Входит в состав округа Шердинг» исполнитель остаётся неназванным, «Шердинг» поясняет «округа». У спорной запятой между «состав» и «округа» доступен также разбор с перечислением. |
| 43 | «Тойффелен» — подлежащее, «коммуна» — именное сказуемое. Пустые скобки сохраняются в тексте. Сочетание «в кантоне Берн» может уточнять «в Швейцарии». |
| 44 | «Согласно Младшей Эдде» указывает источник сообщения. «Если» открывает условие. У «зажарить» сохраняется модальное чтение, «себе» связано с «он». Собственное имя не устанавливает тождество конкретному внешнему объекту. |
| 45 | Страдательное «было распространено» получает подлежащее «слово», иностранное обозначение «tempora» поясняет его. В принятом чтении «Позднее» указывает на время распространения. |
| 46 | «В 1 раунде» задаёт порядковый номер. «Диксона» может быть дополнением, «ниже пояса» уточняет «удары». |
| 47 | В «Все произведённое» причастие занимает место существительного. «Достоянием» характеризует это подлежащее. «Позволяет распределять» сохраняет возможность действия с неназванным исполнителем. |
| 48 | Три названных участника относятся к одному перечислению. Обе числовые пометы сохраняют значения и порядок компонентов. У «24-11» и «14-10» не назначаются владельцы очков. |
| 49 | Пётр Иващенко связан с «озвучивает», Юрий Мазихин — с «озвучивал». Без скобок возможны вставное пояснение и обычное бессоюзное продолжение. |
| 50 | «Диаметром» характеризует «окружность». Дробь 1/8 хранится точным десятичным значением 0.125, у «ширины» сохранён родительный падеж словоформы. Носитель действия «касающуюся» — «окружность». |
| 51 | В «OS — наружный сегмент фоторецепторов» обозначение «OS» выступает подлежащим, «сегмент» — именной частью сказуемого. Расшифровка обозначения не требуется. |

Варианты строятся по частям речи, согласованию, управлению, порядку вхождений и существующим языковым ресурсам. При числовой помете, измеряемом признаке или неизвестном имени система может запросить подтверждение. Для приложений языковое основание — существительное или имя, уточняющее другое существительное. Для самостоятельного пояснения в скобках — связь между двумя предикативными частями. [UD appos](https://universaldependencies.org/u/dep/appos.html) · [UD parataxis](https://universaldependencies.org/u/dep/parataxis.html)

## Как оценивались ответы

Контрольный выбор использует эталонные зависимости только в сценарии приёмки. После записи проверяются исходная строка, координаты вхождений, ссылки графа, вершины содержательных слов и отдельно перечисленные роли и области действия. Для `obj` при «касаться» учитывается управляемое дополнение в родительном падеже при совпадающей вершине. Внутреннее представление группы с предлогом разворачивается по обычным правилам сравнения AG с UD. Каждое из 20 пунктуационных изменений сохранило проекцию исходного графа. Отдельные первые ответы `0` и `?` проверены на пустой памяти во всех 30 подачах.

При независимом выборе изолированные читатели GPT-5.6 Luna с низким уровнем рассуждения видели только предъявленные карточки. На окончательных формулировках 10 из 10 исходных предложений дали ожидаемую запись. Для s45 сохранены и неуспешные попытки. На первый вопрос «Какое слово уточняет „Позднее“?» читатель ответил `0`. Две последующие редакции с вариантами из отдельных слов привели к неверной привязке «Позднее» к «слово». В последней редакции оба варианта показывают непосредственно относящиеся к ним слова — «слово tempora» и «было распространено». Два новых независимых читателя выбрали второе сочетание. Измерение относится к этой десятке, использованной при разработке. На внешнем сервисе JEV серия не запускалась.
