# Вторая десятка Russian-GSD при пропусках и опечатках

Каждое из десяти предложений подано через `submit` в четырёх формах. Сначала исходная запись, затем текст без пунктуации, одна ошибка внутри слова и сочетание обоих искажений. Для предложения о дубе три дополнительные подачи меняют только запятые возле «по оценкам учёных». Всего 43 независимых запуска с пустой памятью на каждой версии.

В этой десятке все исходные предложения оканчиваются точкой. Удаляются запятые, скобки, отдельно стоящие тире и конечные знаки. Проценты и дефисы внутри имён сохраняются. Это моделирует пропуск пунктуации на письме. Стирание цифр, значимых символов единиц или границ между словами требует отдельного опыта.

После изменений исходная десятка воспроизвела те же 52 пробы и контрольные структуры по прежней приёмке. При удалении всех знаков совпали s12, s15 и s19. Для s15 исчезла лишь конечная точка. Для s12 потеря двух запятых вокруг «по оценкам учёных» прежде приводила к записи возраста без оговорки. Теперь все три варианта этого оборота совпали с исходным графом. При полном удалении знаков появилась дополнительная проба о мере. При одновременной опечатке добавляется также вопрос о написании.

Варианты s13, s14, s16, s17, s18, s20 и s21 без пунктуации завершились без записи. С отдельной опечаткой s14 записал буквальное КОАТУ. Семантическое сравнение обнаружило изменение обозначения. Остальные девять искажений слов с исходной пунктуацией дали контрольные графы.

## Сверка

Для исходного текста требуется прежняя последовательность вопросов и вариантов, прежние ответы и число проб. Для искажённого текста контрольный ответ подаётся, если среди вариантов есть однозначно соответствующий ответ. Для пробы о написании выбирается известная составителю исходная форма, если она среди вариантов. Любое слово, которое не искажали, подтверждается буквально. Для искажённого сокращения восстановление исходного обозначения не обосновано. Ответ на новый вопрос о присоединении извлекается из вершины предлога в контрольном графе. В s12 и s19 заданы также контрольные чтения меры «14 метров в охвате» и перечисления «к папе, к кораблю». При новом вопросе без контрольного ответа происходит воздержание. Этот опыт измеряет достижимость исходного чтения при заданных ответах. Рабочий JEV здесь не опрашивается.

Во всех исходных случаях выполняется прежняя проверка по GSD и выбранным семантическим связям. Во всех записанных вариантах сравниваются роли, леммы, падежи, головы и связи участников, эллипсиса и координации, количества, вид события, область и статус утверждения. Позиции отсчитываются по словам с сохранением значимых символов. Дополнительно проверяются соответствующие рёбра записанной группы и буквальный текст наблюдения. Контрольный граф исходной версии получают через тот же вход. Критерий — воспроизведение конкретного контрольного чтения. Другое грамматическое чтение тоже может быть допустимым. На одну подачу отведено 30 секунд процессорного времени. Тайм-аут отмечается отдельно от отказа грамматики.

## Совместимость

Для всех 22 предложений тестового раздела, которые предыдущая версия записывала без выбора, повторно сравнены статусы, число вопросов и метаданные каждого сохранённого слова. Расхождений в этих 22 записях не обнаружено. Для новых правил остаётся тот же критерий: на исходном тексте проверить граф и стоимость выбора, на искажённом — граф, оставшуюся неопределённость и отсутствие записи при отказе.

Начало предложной группы наблюдается при поступлении управляемого слова. Область оговорки подтверждается после установления внешней связи. Для непомеченных запятыми групп обычного утверждения этот выбор выполняется после синтаксического разбора, отдельно для каждой спорной группы. Поддержка признака в корпусе используется только для предложения варианта. Сочетания, которых нет в таблице, также допускают это чтение, когда развёрнутая группа стоит между участником и его сказуемым. Учебное основание — вводные сочетания со значением источника сообщения у Д. Э. Розенталя. [Справочник Розенталя](https://old-rozental.ru/punctum_uk.php?pid=40)

## Воспроизведение

Команды рассчитаны на окружение проекта с pymorphy3. `corpus` указывает на неизменённый тестовый раздел GSD 2.15. Скрипт проверяет его контрольную сумму. Временный каталог для исходной версии должен быть свободен.

```bash
git worktree add --detach /tmp/gsd-noise-original e010b89d18ddd402abcfbaf03c971a2b0082ae4f
PYTHONPATH=/tmp/gsd-noise-original/src python scripts/audit_russian_grammar_noise.py "$corpus" /tmp/gsd-noise-baseline.json
PYTHONPATH=src python scripts/audit_russian_grammar_noise.py "$corpus" noise-results.json --baseline /tmp/gsd-noise-baseline.json --expect docs/evidence/russian_grammar_second_ten/noise-results.json
```
