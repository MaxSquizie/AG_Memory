## Условия приёмки

Проверка подаёт исходный текст через `submit`, читает группу наблюдения и её рёбра. Она сверяет синтаксические вершины, роли основных участников, выбранные области утверждения и ссылки на контролёров. Разметка GSD задаёт вершины и синтаксические роли. Контрольные ожидания для памяти хранятся в проверяющем скрипте. Для s16 три ответа отдельно задают конкретное чтение эллипсиса, названия и исполнителя. Корпус сам по себе не устанавливает исполнителя «сделав». [Скрипт приёмки](../../../scripts/accept_russian_grammar_second_ten.py)

В подсчёте вершин пропускается пунктуация. Нормализация учитывает представление предлога и ряда определений в графе. У двух дефисных имён в s17 сравнивается связь целого слова с предложением. Внутренние зависимости частей имени при этом не оцениваются. Контроль ролей не является полной оценкой LAS. [Правила UD для дополнений](https://universaldependencies.org/u/dep/iobj.html) · [Зависимые предикаты](https://universaldependencies.org/u/dep/xcomp.html) · [Приложение](https://universaldependencies.org/u/dep/appos.html)

В новых исполняемых правилах отсутствуют идентификаторы примеров и списки их участников. Источники лексики — уже подключённые морфологические данные, FrameBank, обучающий раздел GSD и Unicode CLDR. Извлечение рамок, модификаторов и форм месяцев документировано в репозитории. В прежнем формализаторе остаются ручные лексические аннотации. [Происхождение ресурсов](../../../src/ah/russian_grammar/lexicon/SOURCES.txt)

## Результаты

Приёмку прошли 10 из 10 с контрольным выбором (52 пробы). Для s16 потребовалось дополнительно задать чтение, которого нет в GSD. При отказе от выбора записался только s14, для остальных девяти память осталась пустой. [Контроль графа и синтаксиса по каждому предложению](results.json)

В слепом прогоне девять предложений записаны, семь прошли все проверки. Для s13 читатель воздержался при выборе связи QA. В s18 читатель отнёс «мужчина» к «дьявола», а GSD — к «описание». В s19 читатель отнёс «в то же время» к «идти», а GSD — к «должен». В обоих записанных случаях различается по одной вершине. Обе возможности доступны через пробы.

На всех 601 предложениях с воздержанием и ограничением три секунды процессорного времени число записей выросло с 18 до 22 относительно опубликованной базы. Все прежние 18 сохранились. Дополнительные четыре полностью совпали с корпусом по вершинам. Точных деревьев стало 19 вместо 15. Всего совпало 127 из 133 вершин записанных предложений. Превышений ограничения времени стало 119 вместо 106. [Весь тестовый раздел](corpus.tsv)

Проверки этих предложений после пропуска пунктуации и ошибок внутри слова приведены в [отдельном отчёте](noise.md).

## Воспроизведение

Из корня проекта, указав путь к тестовому разделу GSD 2.15:

```bash
PYTHONPATH=src python scripts/accept_russian_grammar_second_ten.py ru_gsd-ud-test.conllu results.json --responses docs/evidence/russian_grammar_second_ten/responses.json --seconds 30
```

Параметр `--require blind` включает строгую оценку слепого прогона. Программа возвращает ненулевой код при расхождении. Ответы изолированных GPT-5.6 Luna получены на минимальном уровне рассуждения. Для s12 и s17 читатель сначала ввёл порядковый номер, который система отклонила, затем повторил прогон с инструкцией копировать слово. Рабочий JEV в этих измерениях не запускался.
