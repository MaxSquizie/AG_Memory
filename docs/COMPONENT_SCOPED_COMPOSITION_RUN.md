## Неизменный дневниковый абзац: фактический T6

Взяты символы `[98865,99084)` исходного текста — восемь предложений от
«Очень жаркий день» до «Вечером занимался». SHA256 отрывка:

Текст, имена и порядок не редактировались.

Изолированный исполнитель видел только короткие system/prompt, без кода, gold,
состояния AH и предполагаемого ответа. Он возвращал только SELECT_LABELS_V1.
Граф и сериализацию строил runtime. Время ожидания исполнителя не является
измерением скорости локальной модели.

Первый проход выявил ошибку самого набора кандидатов: «центр повествования»
дублировал неизвестного участника, позднее — ещё и CHAIN. Ответы `1,2` и `1,4`
оставили оба события незаписанными. После удаления дублирующей гипотезы:

1. Attachment «После завтрака принял Алека» → `1`.
2. Attachment «После чая принял Мамáнтова» → `1`.
3. Первый нулевой субъект → `1` (анонимный, без установленного antecedent).
4. Второй нулевой субъект → `3` (цепочка первого «принял»).

Финальные четыре запроса дополнительно исполнены четырьмя независимыми
изолированными агентами: каждый читал только свой исходный request JSON,
без ответов других исполнителей. Получены те же `1`, `1`, `1`, `3`.
Именно эти ответы использованы в заключительном транспортном проходе;
совпадение всех полей запросов проверяет MailboxBackend.

Проверено восстановлением настоящей AH из журнала:

- APPLIED, **2 committed fragments**, 4 живых пути опоры;
- два событийных N и два G(AFTER), один анонимный участник для обоих событий;
- два N event-anchor («завтрак», «чай») S-accessible, **без root-support**;
- 4 OPERATOR UsageLinks; **0 TimeAssertions** — абсолютного якоря нет;
- лексические T остаются OPEN/UNLINKED; канонический sense и личность автора
  не приписаны; группа «рассказчик + Алек» не создана.

Точный транспортный повтор сохранённых запросов прошёл на текущем коде.
Затем выполнен **native replay в том же runtime**, с теми же source/run inputs:

## Проверки и ограничения

100 целевых проверок охватывают композиционные роли, координацию, scope-защиту,
относительное время, бюджет, Ignition, документный pipeline, binding/replay и
реальный provider adapter. Тестовые ответы scripted; это проверки механик.
Пять старых падений в `test_formalizer_provider_adapter` и
`test_formalizer_run_and_provider` воспроизведены и на исходном `14cc70f`
(legacy ordinal ID / release binding / повтор digest между разными runs).
Они не объявлены исправленными и не скрыты за результатом целевой группы.

**Полной формализации пока нет.** В проверенном абзаце остаются шесть предложений:
безглагольная/качественная предикация, наречные обстоятельства, составное время,
предложная роль неизвестного предиката внутри AND. Сама AND-композиция проверена
отдельно: один корень + два AND_ELIMINATION, отдельное разрешение группы,
восстановление и отзыв. «Покатались на шлюпках и купались» не объявлено успешно
разобранным без ресурса для предложной роли. Неполный первый конъюнкт блокирует
всю композицию, второй не записывается в обход неё.

Дальнейшая работа остаётся на этом дневнике: общая композиция обстоятельств и
нефинитных предикативных центров, совместные аргументы/время и безопасный frontier
коммитов. `EXECUTED` и количество обработанных токенов не равны полноте.
