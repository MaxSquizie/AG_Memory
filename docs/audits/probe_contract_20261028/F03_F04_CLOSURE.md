# F03–F04: границы завершённого исправления

Дата: 29 октября 2026. Контур: native closed selection, включая прямые _probe, choose/choose_domain, динамические страницы исходных границ и совместимые прямые производители. TP generation, JSON naming/open-set, embedding и другие самостоятельные протоколы не переименованы в closed selection: их исходные карточки сохраняются.

## Что закрыто

| Обязанность | Реализация и основание |
|---|---|
| Адресовать предмет вопроса | У каждого прямого производителя явные target_refs либо специализированный inputs. У страниц — region/token refs и payload. Отсутствие декларации блокирует вызов. |
| Различать исходное вхождение и новое использование содержания | Отдельные source focus и interpretation area; никакого переноса владения словами из читаемого контекста. |
| Сохранить различающие данные | Координаты одноимённых участников/предикатов, все grounding descriptions референта, полные доступные источники памяти и текущего наблюдения; отсутствие источника видно. |
| Не подменять гипотезу принятой структурой | DirectProbeInputs объявляет кандидатные интерпретации. Лексика, ссылки, речевой акт/адресат и assertion scope имеют отдельные структурные входы с ролями/вложенностью. |
| Сохранить родительские обязательства | InputSlot показывает заполненное/отложенное содержание, владельцев, контроллер, ограничения согласования, статус вложенности и независимость субъекта; недоступные обязательные опоры блокируют. |
| Передавать установленный выбор | AcceptedSelection связывает слот, payload и proof; используется в ролевых/морфологических, исходных, именных и content-reference цепочках. |
| Не использовать устаревший ответ | Проверки до вызова, после ответа и при использовании зависимого proof; source/parent/structure signatures участвуют в replay. Проверка dependency graph итеративная. |
| Сохранить различия вариантов | Scope labels содержат адреса и роли; quantifier/relative/agreement показывают целые чтения; необъяснимые различия не заменяются внутренними IDs. |
| Один ответ — одна определённая неопределённость | Внешний падеж указывает конкретное выражение и голову; legacy temporal scope спрашивается по одному отношению; гипотеза/страница не выдаётся за готовность всего результата. |
| Объявить требования всех семейств | probe_families содержит общие и специфические required_data для 15 семейств. Общая регистрация не является проверкой истинности их ответов. |

## Проверяемый охват и достаточность

AST-проверка: 75 вызовов с постоянным slot, 66 используемых зарегистрированных слотов; каждый прямой _probe имеет вопрос и явное объявление адреса/входа. Динамические страницы проверяются через structural_tasks. Это доказательство охвата объявлений в исходниках, не исполнения каждого пути.

Необходимость исправлений подтверждена контрастами: одинаковое имя в разных местах; различающий текст за прежним excerpt; отсутствие головы/источника родителя; смена роли при прежнем ключе; отзыв исходной функции после выбора падежа; два временных отношения с разным статусом. Старый вход либо не различал эти состояния, либо старое основание сохраняло право использования.

Локальная достаточность условна: при корректном источнике/кандидатном домене, верном ответе исполнителя и соблюдении объявленных семейных требований перечисленные различия сохраняются до соответствующего потребителя, либо операция явно остаётся незавершённой. Кодовые проверки подтверждают адреса, payload, версии и liveness; человеческую смысловую достаточность произвольного русского текста нельзя доказать одним непустым полем или реестром.

Исправления F03/F04 по выявленным потерям и общему контракту native-вызовов завершены. Это **не** закрытие всех проблем формализатора: F05 — полнота генераторов; F07/F12 — полный пересмотр/инвалидация всех производных снимков; F08 — прочие протоколы; F09 — представимость; F10 — качество слабого исполнителя; F14 — отрицательные основания завершения; F15/F16 — отдельные семантические/policy вопросы сохраняются. Успех сценарного селектора не является испытанием Luna, локальной LLM или GUI.
