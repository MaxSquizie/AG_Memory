# Недочёты, исправленные при подключении oracle V7

Исходная ветка `temp`: коммит `12976bf388ef2b77f06b174eab27f60e49db31dc`. Архитектура и символический gold не изменены. Production integrity-проверки остаются обязательными. Исправления фикстур отдельно отмечены в таблице.

| Недочёт | Как исполнено до исправления | Как должно быть и что исправлено | Причина |
|---|---|---|---|
| Импорт отсутствующего `detect_negation` | Runtime adapter импортировал функцию, которой нет в speech_act | Добавлен лексический detector отдельного токена «не»; native scope определяется деревом конкретной рамки | Runtime adapter не загружался; совпадение подстроки не доказывает отрицание |
| Недостаточно точный fallback-предикат и роли | Preview мог брать INFN перед конечным VERB; у конструкции `у + gen` не было корректной схемы ролей | Конечный VERB имеет приоритет; роли задаются конструкцией/падежами, без позиционного назначения, неоднозначный слот не угадывается | Preview должен сохранять реальные роли, а не порядок слов |
| Общий scope отрицания в projection | Отрицание одного фрагмента могло влиять на проекцию другого; операнд OR мог попасть в плоские assertions | Для native projection используется sealed scope конкретной рамки. Составной scope сохраняет владельца и не утверждает каждый операнд | Структурное присутствие не означает истинность отдельного факта |
| POS pymorphy3 сохранялся специальным объектом | `tag.POS` участвовал в сравнении как внутренний тип pymorphy | POS приводится к plain string; неизвестный POS остаётся None | Контракт morph не должен зависеть от специальных правил сравнения библиотеки |
| R-X lexical keys требовали `.parse` | Пользовательский MorphProvider с `.analyze` нельзя было использовать при сборе R-X ключей | Поддержан основной MorphProvider `.analyze` и legacy `.parse` | Один и тот же публичный morph-контракт должен работать по всему pipeline |
| Run binding использовал изменённое observation | Native этап дополнял observation, после чего run_from_state мог сравнивать hash уже другого снимка | Binding закрепляет исходное observation, переданное interpret_full, вместе с ResourceSnapshot | Повтор должен сверяться с теми же входами, которые закреплены до исполнения |
| Синтетическая рамка получала O-ground | build_plan всегда ставил `truth_grounds=('O',)` даже без настоящего observation | O допустим только при совпадении text/observation_id/version; иначе COND5 и отсутствие факта | Структурная/интерпретационная гипотеза не является наблюдением мира |
| BoundVar в каноническом quantified-узле | Конструктор не задавал метку quantified scope для узла с BoundVar | Типизированный узел с BoundVar получает semantic_scope=QUANTIFIED | FORALL body обязан быть валидной пропозицией с переменной |
| Неправильные неизвестные/вырожденные временные случаи | Два неизвестных POINT могли сравниваться как равные; одноточечная производная область могла сохранять неверный kind | Неизвестная граница не даёт лицензии; вырожденный EXISTENTIAL нормализуется в POINT; уточнено покрытие одноточечного CONTINUOUS | Отсутствие времени не доказывает равенства, а одноточечные формы должны быть эквивалентны |
| Диагностика возможной одновременности | Алгебра возвращала только boolean гарантии | Добавлен единый результат guarantee + INTERVAL_BOUNDARY_UNKNOWN / SIMULTANEITY_NOT_ESTABLISHED | Возможное пересечение не должно выглядеть как доказанное противоречие |
| Pipeline test fixture без release | Тест ожидал OK, передавая `release=None` | Тест создаёт изолированный подписанный TEST_ONLY release; отсутствие release отдельно проверяется как RESOURCE_MISSING | Исправляется фикстура, а не отключается обязательный production resource boundary |
| AH test fixture с `ops_digest='d'` | JournalIntegrityError возникал при проверке поддельного digest | Digest считается из настоящего MutationPlan; отдельный негативный тест проверяет отказ при неправильном digest | Integrity-проверка была корректной, вход теста — нет |
| Goal tests проверяли устаревший memory shortcut | Некорректно типизированный memory-вход мог считаться достаточной проверкой on-demand вывода | Основные проверки используют настоящие SupportRecord, лицензированные premises, AH/WAL и GOAL_DECISION; неподтверждённая memory-форма проверяется как отказ | Положительный результат не должен обходить validation premise/form |
| Oracle не вызывался тестами проекта | JSON corpus проходил только собственную проверку формата | Добавлены CLI driver, concrete adapter, независимый comparator и параметризованный pytest по всем case IDs | Валидность gold не доказывает работу реализации |
| Непривязанный кейс мог потеряться в успешном отчёте | Не существовало runtime-учёта недоступных действий | Preflight блокирует весь кейс; результат BLOCKED со списком причин, runtime exception — FAIL; CLI возвращает 3 при неполном покрытии | «Не запускали» нельзя превращать в «проверили» |
| Полное сквозное покрытие остаётся неподтверждённым | 126 видов действий gold не имели API binding | Сейчас привязаны 16 видов; 1319 кейсов PASS, 1223 BLOCKED, включая все 640 pipeline кейсов. Остальное требует дальнейшего binder, independent snapshot compiler и process crash harness | Количество кейсов и положительных компонентных векторов не заменяет вертикальный прогон |

Проверки и ограничения воспроизведения приведены в [интеграционном отчёте](FORMALIZER_V7_ORACLE_INTEGRATION.md). Сырые фактические результаты и hashes находятся в [formalizer_v7_oracle_run](formalizer_v7_oracle_run/README.md). PASS ворот архитектуры этим документом не объявляется.
