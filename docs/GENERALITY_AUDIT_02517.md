# Аудит общности v0.25.17

## Проверенная граница

Аудит выполнен относительно полного архива v0.25.16. Проверены девять изменённых
production/prompt-файлов: event normalization, linguistic candidate graph,
adaptive parser, canonical hypernode enrichment, Integration, Orchestrator,
публичная bootstrap-граница, локальный tick benchmark и инструкция modifier
attachment.

Автоматическое сравнение охватило 331 уникальный текст из broad, regression,
adversarial и ellipsis acceptance. Среди 878 добавленных строк production/prompt
нет ни одного точного вхождения текста case. Отдельный поиск не обнаружил новых
ветвей fuzzy/typo recovery, embeddings или Levenshtein. Полные результаты
сохранены в `verification/02517/generality_audit.txt`.

## На чём основаны решения

| Механизм | Допустимые основания | Что не используется |
| --- | --- | --- |
| Удаление ложных `FOLLOW`/`CAUSE` | тип frame coordination, aspect, явные connectives | правдоподобный порядок событий, общий участник как доказательство причины |
| Enrichment существующего `N` | строгое включение role map, равенство общих refs, уникальность | совпадение только предиката/субъекта, перенос ролей из более подробного события |
| Межпредложная кореференция | morphology agreement и полный набор локальных кандидатов | выбор «наиболее вероятного» человека моделью |
| Relative time | явная TIME-фраза и timezone-aware timestamp внешнего turn | время машины как скрытый актант каждого факта |
| Quantified NP boundary | локальные head/following-span и фиксированный структурный выбор | перечень временных единиц или известных существительных |
| Ellipsis source | clause graph, локальные proposition refs, уникальное сопоставление реализаций | номер case, таблица предикатов, словарь ожидаемых ролей |
| Замена controller | уже установленная identity исходного графа | имя участника или фиксированная модель управления глагола |
| Повторённый конечный предикат | adjacency, adversative coordinator, dash, lemma identity, polarity contrast | конкретный глагол или объект |
| Modifier attachment | один source-only semantic choice среди перечисленных owners | ближайшее существительное как автоматический ответ |
| Стабильность tick benchmark | сборка внешнего циклического мусора до измерительного окна | изменение порога, объёма графа или исключение GC самого измеряемого workload |

## Литералы условий

Машиночитаемый AST-инвентарь находится в
`verification/02517/control_literals.json`. В новой функции повторённой рамки это
только варианты тире и закрытый класс противительных союзов. В ellipsis recovery
нет content vocabulary; `A` является префиксом локального runtime-id. Остальные
строки относятся к пунктуации, служебным словам, POS/morphology, протокольным
меткам и metadata.

## Контрпримеры и отрицательные проверки

- Для повторённого сказуемого отдельно проверены отсутствие переноса при той же
  полярности, другом предикате и отсутствии тире.
- Для сильной пунктуации проверены оба исхода: восстановление событийной рамки и
  сохранение настоящего именного сказуемого.
- Вложенный граф проверен с одним matrix/content деревом, с controller через
  RECIPIENT и рядом с независимым корнем. Ни одна восстановленная ссылка не может
  остаться направленной на дочерний узел исходного события.
- Выбор корня проверен при разных предлогах места и при цепочке noun → pronoun:
  алгоритм использует identity alias, а не совпадение конкретного предлога.
- Canonical enrichment проверен в обоих направлениях и для несравнимых наборов
  необязательных ролей.
- Координация сохраняет только runtime temporal candidate; canonical relation и
  causal candidate отсутствуют без отдельного источникового основания.

Тестовые предложения и fixtures содержат разные слова для воспроизведения
структурных классов. Они не импортируются production-кодом и не участвуют в
ветвлении алгоритма.
