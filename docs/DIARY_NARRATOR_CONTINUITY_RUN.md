# Дневник: сохраняемый рассказчик и короткие пробы без потолка

Дата проверки: 2026-10-13. Основа: `7de17b4f3ad3f075335fdd89b4ff2c64b108ca55`.
Запись 28 июля, диапазон исходного дневника `[94816,95107)`, 291 символ.
Ресурсный release — **TEST_ONLY**. Короткие пробы независимо отвечал агент
по предъявленным вариантам, без доступа к ожидаемому графу. Jev не запускалась.

## Принятый контракт

- `SOURCE_CARRIER_V1`: текущий анонимный рассказчик сохраняется в источнике
  до положительного основания смены. Дата, абзац и окно не меняют его Ref.
  Кандидат `NARRATOR_SHIFT` требует свидетельства смены перспективы; чужое
  третьеличное действие само по себе её не меняет. Цитаты не наследуют
  внешнего рассказчика автоматически.
- `SOURCE_WINDOW_V2`: нулевой накопительный лимит вызовов/токенов означает
  отсутствие соответствующего потолка. Учёт и replay сохраняются. Конечные
  наборы кандидатов, ограничения структур и контекста модели остаются.
- Факт и подтверждённые связи могут храниться без отдельной программы вывода
  для каждого узла. Следование не доказывает причинность. Автоматическая
  F-проекция сквозь произвольный OPEN-модификатор не добавлена.
- `DEPENDENCY_REJECTED` исключает вопрос об отвергнутой ветви из актуальных
  уточнений. Ответ/Decision остаются в истории. Неопределённость `?` и
  неоднозначность не считаются отвержением.

Подробности: [NARRATIVE_AREA_REFINEMENT.md](NARRATIVE_AREA_REFINEMENT.md).
Предыдущий [отчёт](DIARY_AREA_REFINEMENT_RUN.md) описывает прежний запуск;
его ограничения по бюджетам и локальности рассказчика не являются текущей нормой.

## Адресация на границе двух дневниковых записей

На реальном диапазоне `[94447,95107)` проверены два «принял» из записей
27 и 28 июля. Окна контекста различны: `[0,369)` и `[369,660)`, а Ref
рассказчика совпадает. При отдельной адресации этих окон с тем же source_id,
редакцией и настоящими диапазонами Ref также совпадает. Эта проверка
исполняет конструктор области; она **не** является полным семантическим
прогоном обоих дней.

## Оставшиеся границы

- «К тому же месту»: конкретный референт всё ещё не установлен; относительное
  направление сохраняется. Единственная диагностика уточнённой версии —
  `NOMINAL_REFERENCE_UNRESOLVED`.
- Дочерние события под открытым модификатором структурно доступны, но
  самостоятельная утверждённость требует общего контракта её выделения.
  Задача не решается объявлением каждого OPEN-узла логическим оператором.
- Текущий native-разбор получает источник целиком. Для будущего разбиения
  его коммитов на части нужно переносить подтверждённые смены рассказчика,
  а не только исходный Ref. Реальной смены рассказчика в этом фрагменте нет;
  её семантическое распознавание данным прогоном не доказано.
- Два файла с разными source_id не отождествляются молча. Старые записанные
  интродукции не мигрируют без объявленной переинтерпретации.

Тестовые наборы не запускались; проверялся реальный фрагмент, его граф,
replay/recovery и отзыв. Полная формализация дневника не заявляется.
G0/G5 и production-готовность не переоценивались.
