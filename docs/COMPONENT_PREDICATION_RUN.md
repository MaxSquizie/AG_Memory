## Что записано

| Исходное предложение | Результат последнего независимого прогона |
|---|---|
| Очень жаркий день. | Внешний OPEN-модификатор «очень», внутри качественная предикация; внутренняя истина отдельно не выводится |
| Доклад кончился вовремя. | Внешний OPEN-модификатор «вовремя» над событием, UsageLink UNKNOWN |
| После завтрака принял Алека. | Событие с анонимным субъектом и AFTER к структурному якорю «завтрак» |
| В два часа сорок пять минут отправились вверх. | Не записано: количественная группа/clock и направление ещё не замкнуты |
| Покатались на шлюпках и купались. | Структура AND + предложный модификатор построена, но фрагмент не записан: предыдущая группа отсутствует среди разрешённых antecedents |
| Вода была хорошая. | Качественная предикация; связка учтена морфологически, отдельного BE-факта и TimeAssertion нет |
| После чая принял Мамáнтова. | Событие + AFTER; тот же анонимный субъект, что у первого «принял» |
| Вечером занимался. | Внешний OPEN-модификатор «вечером»; субъект внутреннего события совпадает с субъектом обоих «принял» |

Итог: `EXECUTED`, терминальный `APPLIED`, **6 коммитнутых фрагментов из 8 предложений**,
13 N/G, 8 опор, 7 UsageLink, 0 TimeAssertion. Это структурное покрытие,
не утверждение полного понимания всех модификаторов. Временная фраза без даты
не превращается в придуманную абсолютную временную метку.

Три разрешённых пропуска singular/masculine ссылаются на один `M:implicit:…`.
Личность автора, пользователя или Николая II из имени файла не устанавливалась.
Plural не был автоматически объявлен группой «аноним + Алек».

Последняя проба вернула `4,6`: два упоминания одного уже установленного entity_ref.
Равенство проверено программой; raw MULTIPLE_ADMISSIBLE сохранён. Разные люди
или неразрешённые цепочки этим правилом не объединяются.

## Что реально ломалось и исправлено

1. Морфологический вариант VERB считался доказанным дополнительным центром.
   Теперь полные варианты клаузы конкурируют целиком; ADJF/ADJS и связка следуют
   выпущенной политике, частичные альтернативы не исчезают.
2. Scoped native commit успешно завершался, после чего DocumentProcessor падал
   в старом TemplateCompletion. Native receipt теперь защищён на общей границе
   сервиса; вложенная proposition не уплощается в неверный UI-предикат.
3. В вопрос выбора структуры попала фраза о запрете отдельной truth-support.
   Исполнитель отверг её как отрицание смысла «занимался вечером». Из короткой
   пробы удалено правило хранения: вопрос теперь только о прикреплении структуры.
   Семантика UNKNOWN/factivity не ослаблена.
4. Вопрос референции содержал непрозрачный gap ID и весь абзац. Исполнитель
   принял целью plural «отправились» вместо второго singular «принял».
   Теперь вопрос явно называет целевую клаузу, роль, предикат, диапазон и морфологию.
5. Два выбранных указателя на одного установленного участника давали ложную
   неоднозначность. Добавлена проверка равенства entity_ref с аудитом выбранных ссылок.

Повторная инвентаризация всех 17994 токенов: T0–T4, каждая проба получает
INSUFFICIENT_CONTEXT, T6 не вызывается. 4070 frame-кандидатов, 4064 COMPONENTS_V1,
373 запроса в 194 окнах, 1780 вопросов о предложных связях, 374 о пропущенных

Диагностики считаются по кандидатам, не по уникальным предложениям.

Время 215,81 с против 82,15 с предыдущей более узкой грамматики. Расширение
пространства разборов существенно удорожило перечисление; это отдельный долг
по факторизации дерева, не повод скрыто обрезать кандидатов или считать их верными.

Следующий блок на том же документе:

- Количественные именные группы и составное clock-выражение: сохранять все
  числительные/единицы и их диапазоны; не путать clock с длительностью, не
  угадывать календарную дату или 02:45/14:45 без основания.
- Прикрепление времени и направления к одному событию с явными альтернативами
  scope. Нельзя просто удалить «в два часа сорок пять минут» ради коммита глагола.
- После разрешения этой клаузы — повторить plural-цепочку «отправились →
  покатались → купались» и проверить единый неопознанный групповой референт.
- На всём дневнике остаются вложенный scope, несколько модификаторов, control,
  сложные координации и фактивность неизвестных значений. Этот абзац их не закрывает.

Никаких правил под имена/фразы дневника в runtime не добавлено. Новые механизмы
распределены по небольшим модулям, ресурсные данные fixture помечены TEST_ONLY.
