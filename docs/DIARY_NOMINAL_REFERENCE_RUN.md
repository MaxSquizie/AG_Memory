# Дневник: референтная группа «к тому же месту»

## Что изменилось

Исправлен структурный тупик на частице внутри именной группы. Версионируемый
словарь определяет возможные указатели и модификаторы тождества; короткая
проба подтверждает их функцию в конкретной группе. Код собирает дерево,
сохраняет морфологию, исходные anchor refs и ограничение SAME. Частица не
удаляется и не становится самостоятельным фактом. Правил для слова «место»,
имён, даты или номера записи в runtime нет.

Выбор референта — отдельная короткая проба по frozen чтению активного
workspace Ignition. Кандидаты сопровождаются живыми привязками и исходными
текстовыми фрагментами. Принятый выбор может записать обычную привязку
NOMINAL_REFERENCE с receipt и зависимостью от основания; отсутствие выбора
блокирует соответствующий фрагмент и сохраняет вопрос уточнения.

Нормативный контракт: [NOMINAL_REFERENCE_GROUPS.md](NOMINAL_REFERENCE_GROUPS.md).

## Что остаётся

1. Внешняя область «отправились вверх к тому же месту». Проба не выбрала между
   совместными описаниями движения и вложением одного модификатора в другой.
   Разрешённая внутренняя группа может спросить память независимо, но этого
   недостаточно для коммита внешней области.
2. Загруженная память содержит лес из прогулки 27 июля, но не устанавливает,
   что это место поездки «вверх». Ближайший совместимый объект не назначается
   референтом автоматически. Для доказанного выбора нужен дополнительный
   контекст более ранних записей либо уточнение.
3. Успешный коммит NOMINAL_REFERENCE и последующий отзыв в этом прогоне
   не упражнялись: поддержанного референта не оказалось. Наличие кода
   write-boundary/liveness не выдаётся за наблюдавшийся успешный сценарий.

Количество коммитов осталось прежним. Доказанный прогресс этого прохода —
сборка группы, сохранение смысла частицы, независимое обращение к памяти и
корректное сохранение неразрешённости вместо ложной сущности.
