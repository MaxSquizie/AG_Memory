# Неявная группа и перспектива повествования

## Семантика

Пропущенное подлежащее множественного числа лицензирует группу, но не её
полный состав. Новое событие не обязано продолжать действие ближайшей
упомянутой группы. При установленной перспективе первого лица группа может
включать рассказчика и неустановленных остальных участников. Личность
рассказчика при этом может оставаться неизвестной. При повествовании от
третьего лица включение рассказчика не следует из грамматики.

Область перспективы проверяется для целевой клаузы по исходному контексту.
Цитата, вложенное сообщение, смена точки зрения и явно продолжаемое действие
других участников не разрешают механически переносить рассказчика внешнего
текста. Окончание глагола само по себе не устанавливает первое лицо. Для явно
выделенных цитат/вложенных эпистемических областей внешний кандидат группы
не предлагается; иные смены перспективы остаются предметом закрытой пробы.

## Выбор

`ProposalPolicy.composition.narrative_groups` включает контракт
`OPEN_NARRATIVE_GROUP_V1` и ссылается на зарегистрированный STATE sense и
реальный TemplateMap с ролями SUBJECT (группа) / OBJECT (участник).
Loader проверяет ресурсную связность, T5 — существующий T и роли в AH.
Отсутствующий mapping не заменяется открытым шаблоном.

Перед seal сохраняются кандидаты:

- прежняя группа при поддержанном тождестве;
- неустановленная группа без подтверждённых членов;
- отдельная группа с поддержанным рассказчиком и неизвестным остальным составом.

Кандидат рассказчика может ссылаться на локальное упоминание, разрешённый
предыдущий пропуск или живого участника активного workspace Ignition. Для
памяти проба получает исходные выдержки из опор именно этих активных
кандидатов. Глобальный поиск рассказчика по всей AH не используется.
Если подходящий референт не установлен, допустима анонимная интродукция в
контексте источника; сохраняемый рассказчик и независимые проверки его
участия определены в [NARRATIVE_AREA_REFINEMENT.md](NARRATIVE_AREA_REFINEMENT.md); она не отождествляется с загрузившим файл пользователем.
При SOURCE_CARRIER_V1 продолжение рассказчика использует один Ref источника;
уже существующие независимые интродукции не сливаются по одному ярлыку.

Модель отвечает закрытой числовой меткой. Выбор проверяет одновременно
перспективу целевой клаузы и основание участия данного рассказчика. Соседство
имени, совместимое число или единственность кандидата не доказывают членство.
Варианты с одним ID группы, но разными утверждениями о членстве не считаются
эквивалентными. При неподдержанном выборе сохраняются варианты и вопрос
уточнения. Если грамматическое множественное подлежащее лицензировано, отдельное
D-решение о существовании группы позволяет сохранить её без установленных
членов; исходное решение о тождестве остаётся неразрешённым. Молчание не
подменяется включением конкретных людей. Исчерпание вычислительного бюджета
или неполный структурный поиск этим правилом не обходятся.

## Граф и долговечность

Группа — неявный M с `participant_kind=GROUP`, `membership_status=UNKNOWN` и
грамматическим минимумом два. Это не замкнутая K из одного рассказчика и не
выдуманный второй человек. Для подтверждённого участия строится отдельное
известное N отношения членства:

`GROUP_HAS_MEMBER(SUBJECT=G, OBJECT=M_рассказчик)`.

Имя sense в production задаёт релиз. Участие других лиц из ближайших
предложений не утверждается. Нет полного списка, точного количества или
доказательства, что группа отличается от каждой ранее встреченной группы.
Числовой COUNT, использующий такой неявный групповой M как перечисление
участников, возвращает UNKNOWN.

Обычный T5/T6 создаёт M, привязку участника, N членства и O-support в одном
допущенном фрагменте с событием. Отдельного writer нет. Привязка
`NARRATIVE_MEMBER` хранит решение, FIRST_PERSON, диапазон контекста и, для
памяти, исходную привязку и конкретные опоры. Write boundary проверяет живую
привязку, соответствие Ref и frozen CONTEXT_READ текущего запуска. Живость
зависит от исходной привязки/опор; source retraction и plan exclusion
распространяются обычным каскадом. Отзыв данной записи не отзывает независимые
факты о рассказчике. При replay выбор и контекст заморожены.

## Морфологические основания

В привязках новых упоминаний сохраняется выбранное для данного frame
морфологическое чтение. Отвергнутые варианты R1 не становятся основанием
числа/рода последующей кореференции. Исторические привязки не переписываются;
их уточнение требует объявленной переинтерпретации.
